# Professional Profile
STATUS: APPROVED
VERSION: 1.0
LAST UPDATED: 2026-08-15

Public identity uses display/artistic name. Legal identity remains private.

## Public fields
display_name, slug, headline, bio, verified age, languages.

## Appearance
height_cm, weight_kg, bust_cm, waist_cm, hips_cm, eye_color_id, hair_color_id, hair_length_id, body_type_id, has_tattoos, has_piercings.

## Location
state/city, primary region/neighborhood, additional service regions. Never public residential street address.

## Service metadata
in-person/virtual, availability, structured services/categories, optional price display (fixed/from/negotiable/hidden).

## Contact
WhatsApp, phone, Telegram with individual visibility controls.

## Privacy
Optional physical fields can have show_* controls. Hidden values must not participate in public filters.

Categorical filter values use controlled reference tables. Bio is sanitized plain text. Advertiser gets profile preview before publication.

Account, verification, profile and media statuses remain separate state machines.
